# win-support-scripts

Скрипты техподдержки Windows: Континент TLS, КриптоПро, Рутокен, `*.cap.ru`, тонкий клиент 1С.

Запуск — двойной щелчок или `MENU.bat`. Отчёт на рабочий стол: `SupportLogs\<дата-время>\`.

**Не делают:** отключение Secret Net / Dallas Lock, экспорт закрытых ключей, кнопку «Восстановление TLS».

Эскалация: АУ «ЦИТ» · «Лидер софт» · коммерческий отдел.

---

## Как пользоваться

1. Откройте `MENU.bat` и введите номер.
2. При запросе прав — запустите от имени администратора.
3. Папку отчёта приложите к заявке.

На заявке про TLS / `*.cap.ru` начинайте с **15**.

---

## Скрипты

| Файл | Зачем нужен |
| --- | --- |
| `MENU.bat` | Общее меню: выбрать скрипт по номеру, не искать файл вручную. |
| `00-sborshik-polnoy-diagnostiki.bat` | Полный сбор фактов: ОС, сеть, DNS, продукты, службы, сертификаты, носители, журналы. Универсальный первый шаг, когда непонятно, с чего начать. |
| `01-dns-ne-rabotaet.bat` | Когда имена `*.cap.ru` не открываются. Проверяет DNS, `hosts`, прокси; по желанию сбрасывает кэш DNS. |
| `02-cryptopro-licenziya.bat` | Когда сертификат «не действителен» только в КриптоПро. Показывает срок лицензии CSP — часто она просто истекла. |
| `03-cryptopro-konteynery-i-sertifikaty.bat` | Когда «ключ не существует» или нет контейнера. Смотрит считыватели, контейнеры и открытую часть сертификатов (ключи не копирует). |
| `04-cryptopro-sluzhby.bat` | Когда КриптоПро «завис». Показывает службы и по подтверждению `Y` перезапускает их. |
| `05-continent-tls-shlyuz-i-adresa.bat` | Когда SSL / `0x8009030d` к `cb.cap.ru`. Проверяет основной и резервный шлюз (`cb` / `cb1` / `cb2`) и подсказывает, какой адрес ставить. |
| `06-continent-tls-ne-vosstanavlivat.bat` | Когда всплыло «Восстановление TLS» (часто сборка 1440). Напоминает **не нажимать** и куда эскалировать («Лидер софт» / ZTN). |
| `07-continent-tls-obryv-sessii.bat` | Когда после смены сертификатов 1С/TLS всё ещё «старые». По `Y` завершает процессы TLS в трее, чтобы зайти заново (часто ещё нужен апдейт 1482→1483). |
| `08-rutoken-i-nositeli.bat` | Когда TLS не ставится (`0x80070643`, «неправильный алгоритм»). Смотрит Рутокен и дату драйвера — сначала драйвер, не сертификаты. |
| `09-moy-ip-dlya-zayavki.bat` | Когда сертификаты и TLS живые, а `*.cap.ru` всё равно недоступен. Печатает IP для белого списка ЦИТ. |
| `10-vipnet-status.bat` | Когда нужно понять, стоит ли ViPNet и жив ли он. К туннелю Континент TLS не относится. |
| `11-secretnet-studio-status.bat` | Статус Secret Net Studio. Только диагностика — защиту не выключает. |
| `12-dallas-lock-status.bat` | Статус Dallas Lock. Только диагностика — защиту не выключает. |
| `13-1c-adresa-baz.bat` | Когда в тонком клиенте прописан `cb.cap.ru` вместо `cb1`. Показывает строки из `ibases.v8i`, файл баз не меняет. |
| `14-1c-gateway-timeout.bat` | Когда Gateway timeout на `/e1cib/login`. Собирает факты для заявки; это ошибка сервера 1С, не локальная починка. |
| `15-razbor-zayavki.bat` | Главный разбор заявки TLS / сертификатов / `*.cap.ru`. Сверяет ПК и печатает формулировки закрытия: ситуация → действие → результат. |
| `16-obnovit-crl.bat` | Когда цепочка ругается на отзыв. По `Y` сбрасывает кэш CRL Windows; сертификаты не удаляет. |

Вспомогательные файлы: `_lib.bat` (общее логирование), папка `ps\` (проверки на PowerShell).

---

## Краткие правила

- Клиент TLS не ставится → сначала драйвер Рутокена (даже если токен в PnP «OK»).
- Обновление TLS: **1482 → 1483**.
- Драйвер старше 18 месяцев — старый; свежий — в пределах 12 месяцев.
- Три сертификата в заявке не смешивать: личный / серверный / корневой.
- PowerShell-файлы: UTF-8 BOM + CRLF.
